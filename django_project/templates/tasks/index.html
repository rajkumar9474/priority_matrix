                📖 How to Use Priority Matrix

                👋 Welcome!

                Priority Matrix helps you organize tasks using the Eisenhower Matrix method. This proven technique helps you prioritize by urgency and importance, making you more productive and focused.

                🚀 Getting Started

                1

                Add Your First Task

                Click the "+ Add" button in the Tasks panel to create a new task. Give it a meaningful title.

                2

                Drag to Prioritize

                Grab the colored token (circle with task number) and drag it to the appropriate quadrant on the matrix.

                3

                Complete Tasks

                Click the checkmark (✔) button on any task to mark it as done. Completed tasks move to the Completed tab.

                🎯 Understanding the Matrix

                1

                🔴 Urgent & Important

                Do First: Critical tasks that need immediate attention.

                • Deadlines today or tomorrow
                • Emergencies and crises
                • Critical meetings or calls
                2

                🟡 Important • Not Urgent

                Schedule: Important tasks to plan and work on strategically.

                • Long-term projects and goals
                • Planning and strategy
                • Personal development and learning
                3

                🟢 Urgent • Not Important

                Delegate: Tasks that need doing but not by you.

                • Interruptions and distractions
                • Some calls, emails, meetings
                • Tasks others can handle
                4

                ⚪ Not Urgent • Not Important

                Eliminate: Time-wasters to minimize or remove.

                • Busywork and trivial tasks
                • Excessive social media browsing
                • Activities that don't align with goals

                ✨ Key Features

                🎨

                Color-Coded Tasks

                Each task gets a unique color for easy visual identification across the matrix.

                🔢

                Task Numbers

                Every task has a unique number displayed on its token for quick reference.

                🔄

                Drag & Drop

                Move tasks between quadrants by dragging their tokens. Drag back to a task to return it to the list.

                📊

                Multiple Views

                Switch between tabs to see tasks by status: Not Assigned, Completed, or by each quadrant.

                ✏️

                Edit Tasks

                Click the pencil icon or select a task and press F2 to rename it.

                ☁️

                Cloud Sync

                Your tasks are saved to the server and accessible from any device with your account.

                ⌨️ Keyboard Shortcuts

                1 2 3 4 Move selected task to quadrant 1, 2, 3, or 4
                0 or Backspace Return selected task to the task list
                Space Toggle task completion (mark done/undone)
                F2 Rename selected task
                Esc Close modal dialogs or cancel editing

                💡 Tips & Tricks

                • Hover over tokens: Hover over any token in the matrix to see the full task title in a tooltip.
                • Double-click to jump: Double-click a token in the matrix to jump to that task in the list.
                • Right-click menu: Right-click any token in the matrix for quick actions like marking done or deleting.
                • Shift+Click: Hold Shift and click a token to quickly mark it as done.
                • Click to select: Click any task in the list to select it (highlighted border).
                • Reorder in quadrants: Drag tokens within the same quadrant to reorder them.
                • Task counts: Each tab shows the number of tasks in that category.
                • Customize appearance: Use the Settings button to customize colors, fonts, and behavior.

                🌟 Best Practices

                🎯 Start Each Day

                Review your matrix at the start of each day. Focus on Quadrant 1 (Urgent & Important) first.

                ⏰ Schedule Quadrant 2

                Block time for Quadrant 2 tasks (Important but not urgent). These drive long-term success.

                🚫 Minimize Quadrant 4

                Try to eliminate or minimize Quadrant 4 tasks. They're time-wasters.

                🔄 Review Weekly

                Do a weekly review to reassess priorities and move tasks between quadrants as needed.

                ✂️ Break Down Big Tasks

                Large projects should be broken into smaller, actionable tasks for better tracking.

                🎉 Celebrate Wins

                Mark tasks complete regularly to track progress and stay motivated!

                🔧 Troubleshooting

                ❓ My tasks disappeared!

                Check the different tabs - your tasks might be in the Completed tab or one of the quadrant tabs. If you logged out and back in, your tasks are stored in your account.

                ❓ Token won't drag

                Make sure you're clicking directly on the token (colored circle). Completed tasks can't be dragged - unmark them as done first.

                ❓ How do I reset my tasks?

                Open Settings → Advanced tab → "Reset Tasks" button. Warning: This deletes all tasks permanently!

                ❓ Can I access my tasks from different devices?

                Yes! Your tasks are saved to your account. Just log in from any device to access them.

                📚 About the Eisenhower Matrix

                The Eisenhower Matrix, also known as the Urgent-Important Matrix, was popularized by U.S. President Dwight D. Eisenhower. He famously said:

                "What is important is seldom urgent, and what is urgent is seldom important."

                This method helps you distinguish between tasks that are truly important versus those that just seem urgent, enabling better decision-making and time management.
